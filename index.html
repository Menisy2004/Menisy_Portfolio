AI Question Generator Also called InterQuest
RAG · Local build
Python · FastAPI · LangChain · Gemini API · PyPDFLoader · Ollama · FAISS · Jinja2 · HTML · CSS · JavaScript

ProblemTurning a long PDF of study material into practice questions takes time, and an answer is only useful if you can trace it back to the source.

SolutionUpload a PDF and get a focused set of review questions. Each answer is retrieved from the uploaded document, so it stays grounded in your own material.

  • Question generation: PyPDFLoader and text chunking feed a LangChain refinement chain that uses Gemini to write the questions.
  • Grounded answers: document chunks are embedded with Ollama's nomic-embed-text model and indexed in FAISS; retrieval-augmented question answering returns answers from the uploaded document.
  • Upload and review interface: drag-and-drop PDF upload with file validation, a 30 MB limit and generation feedback. Questions appear as interactive cards with on-demand answer reveal and a copy button for the whole set.
  • API: FastAPI endpoints for question generation and for retrieving each answer individually. Uploaded PDFs are processed through temporary files that are removed afterward, and retrieval chains are held in in-memory sessions.
